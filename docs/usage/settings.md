# 答题、设置与状态面板

用户脚本与扩展共用本文的答题规则。用户脚本从管理器的“HV-PonySolver 设置”菜单操作；扩展从工具栏按钮进入设置页。各平台可见控件见下表。

## 设置入口

| 设置                                       | 用户脚本菜单                 | 扩展设置页 |
| ------------------------------------------ | ---------------------------- | ---------- |
| 自动/手动模式、点击/提交延迟               | 支持                         | 支持       |
| 面板位置、显示条数、紧凑模式、csp 显示限制 | 支持                         | 支持       |
| 模型 Key 与下载次数查询                    | 支持                         | 仅远程版   |
| 失败随机答案、保留已勾选答案开关           | 当前菜单不提供，使用默认行为 | 支持       |
| 单独下载模型按钮                           | 当前菜单不提供               | 仅远程版   |

## 答题与面板行为

答题模式默认为 `auto`。自动模式会在识别成功后勾选答案并经过配置的延迟点击页面原生提交按钮；`manual` 模式只把识别结果写入面板，不点击答案或提交。识别失败时随机答案默认开启，可以在扩展设置页关闭。

“保留已勾选答案”默认开启，允许用户在识别过程中手动答题：

- 手动勾选与程序自动勾选会分别跟踪，程序不会取消手动项；在自动勾选间隔中手动选中的答案也保持手动身份。
- 手动项与新旧自动项合计不超过 4 个时保持现状。
- 合计超过 4 个时，仅从自动项中按置信度由低到高移除，目标为总数至多 3 个；手动项本身已超过目标时仍全部保留。提交等待结束后会再次检查实际选中状态，保留期间新增的手动项，也不会重新勾回用户已取消的答案。
- 关闭该开关后，程序会先清空当时已勾选答案，再接管本轮选择与提交。

程序从模型准备开始持续确认验证码、表单提交地址和控件仍属于同一轮。答案框不是预期的 6 个时显示“答案框数量异常”；缺少提交按钮时显示“未找到提交按钮”；表单已脱离页面、提交按钮已脱离或不属于该表单、任一答案框已脱离/不属于表单/被禁用时显示“答案控件不可用”；最终提交按钮被禁用时显示“提交按钮不可用”。若页面在等待期间替换了整组控件、改变控件类型或实际提交地址，本轮会静默取消，旧任务不会继续点击；原生提交控件的 `formaction` 覆写同样参与校验，跨源地址不允许提交，指向同一地址的相对与绝对 URL 视为等价。禁用判断包括 `fieldset` 继承状态，保留首个 `legend` 的可用控件例外。相同验证码发生失败后会冷却 30 秒，连续 DOM 刷新在冷却期内不会重复记录；验证码变化、Key 更新或冷却结束后可重新尝试，历史读取始终最多返回 50 条。

状态面板默认位置为 `top=155, left=1240`，默认只在页面存在 `div#csp` 时显示。关闭该显示限制只改变面板可见性，不会关闭识别。面板默认显示 5 条记录，设置范围为 1–50 条。

与 AADB 等局部切页脚本配合时，如果页面替换 body 内容或 body 节点，PonySolver 会重新挂载原有面板，保留识别状态和答题历史。恢复挂载不依赖“仅在 csp 页面显示”开关；是否显示仍遵循该设置，应用销毁后不会自行恢复面板。

新记录的保留顺序与显示时间分开处理，系统时间回拨后仍保留最新写入的 50 条记录；旧记录继续按原规则读取。历史保存失败时，面板会回滚到已保存的记录并显示错误，不保留未保存条目。扩展的历史裁剪只计算已提交记录，尚未保存的乐观条目不会挤掉旧历史；无法完整读取已提交快照时跳过删除。

用户脚本的新历史按独立 localStorage 键追加，避免同源多标签页覆盖同一份历史；有效的旧历史根键只读保留，与新记录按共享规则合并。每世界读取上限为 50 条；并发写入期间底层独立记录可能暂时超过 50，后续稳定追加会再次裁剪。旧根数据不会为这次调整被强制重写或迁移。

“推理状态：完成 Nms”表示本次识别请求耗时，包含图片传输、排队及必要重试。新答题记录末尾的耗时从本轮开始准备模型时起算，包含模型准备、图片读取、识别和配置等待；自动模式还包含勾选间隔与提交延迟，手动模式则截至识别结果记录。它不包含开始扫描前的页面加载/防抖等待，也不包含提交后的服务器响应与页面跳转。两项耗时使用页面的单调时钟计算，系统校时不会改变结果；记录左侧的时刻仍使用本地时间。旧历史保留原值，不补算缺失阶段。

## 输入格式

延迟接受 0–30000 毫秒的整数或 `min-max` 范围，例如 `500`、`500-1000`；最小值不能大于最大值。面板位置接受非负整数 `top,left`，每个坐标不超过 1000000；“重置面板位置”恢复默认值。历史显示条数接受 1–50 的整数，改变显示条数不会提高每世界持久化读取上限。

## 存储和恢复

用户脚本普通设置由 GM 适配器保存，历史在同源 localStorage；Key 只允许敏感 GM 存储，不降级到页面存储。扩展普通设置和历史在 `storage.local`，远程 Key 在扩展源 IndexedDB。切换扩展为内置模型版不会读取或删除原 Key。

面板隐藏时仍可能执行识别和自动提交。希望只显示识别建议时请选择 `manual`；需要停止运行时停用对应客户端。不要在同一浏览器配置中同时启用用户脚本版和扩展版。
