# 答题、设置与状态面板

用户脚本与扩展共用答题规则。用户脚本从管理器的“HV-PonySolver 设置”菜单操作；扩展从工具栏按钮进入设置页。

## 设置入口

| 设置                                       | 用户脚本菜单                 | 扩展设置页 |
| ------------------------------------------ | ---------------------------- | ---------- |
| 自动/手动模式、点击/提交延迟               | 支持                         | 支持       |
| 面板位置、显示条数、紧凑模式、csp 显示限制 | 支持                         | 支持       |
| 模型 Key 与下载次数查询                    | 支持                         | 仅远程版   |
| 失败随机答案、保留已勾选答案开关           | 当前菜单不提供，使用默认行为 | 支持       |
| 单独下载模型按钮                           | 当前菜单不提供               | 仅远程版   |

## 答题与面板行为

默认 `auto`：识别后勾选答案，按设置延迟点击原生提交按钮。`manual` 只记录识别结果，不点击答案或提交。识别失败时随机答案默认开启，扩展设置页可关闭。

“保留已勾选答案”默认开启，允许用户在识别过程中手动答题：

- 手动项始终保留，包括自动勾选间隔中手动选中的项。
- 手动项与新旧自动项合计不超过 4 项时保留；超过 4 项时，只按置信度由低到高移除自动项，目标至多 3 项。手动项本身已超过目标时仍全部保留。
- 从模型准备到提交等待结束，手动取消的项本轮不再勾回，也不占初始裁剪名额。提交前再次检查实际选中状态，保留等待期间新增的手动项。
- 关闭该开关后，程序先清空当前勾选，再接管本轮选择与提交。

程序从模型准备开始复核验证码、提交地址和控件身份。等待期间替换控件、改变类型或实际提交地址，会静默取消旧轮次。只改变同文档 URL 时，旧等待结算后也会自动接手当前有效验证码，不需要额外 DOM 变化。`formaction` 同样受校验，禁止跨源提交；解析后地址相同的相对与绝对 URL 视为等价。禁用判断包含 `fieldset` 继承状态和首个 `legend` 例外。

| 提示           | 含义                                                   |
| -------------- | ------------------------------------------------------ |
| 答案框数量异常 | 不是预期的 6 个 checkbox                               |
| 未找到提交按钮 | 表单缺少提交按钮                                       |
| 答案控件不可用 | 表单或控件已脱离页面、控件不属于该表单，或答案框被禁用 |
| 提交按钮不可用 | 最终提交时按钮被禁用                                   |

普通处理失败和瞬时初始化失败对同一验证码冷却 30 秒，之后由后续扫描重试；冷却使用页面单调时钟，系统时间前跳或回拨不提前或延迟恢复，连续 DOM 变化不会刷出同类记录。准备或识别阶段的永久模型错误与 Key 拒绝都不因冷却结束或提交按钮启用而重试，应先修复原因；目标变化或已提交的 Key 更新可触发新一轮。

面板默认位置为 `top=155, left=1240`，显示 5 条记录，默认仅在存在 `div#csp` 时可见。AADB 等脚本替换 body 或移除面板后，会继续发现新验证码并重新挂载原节点，保留状态与历史；body 暂时缺失时等待重新插入。挂载恢复独立于 csp 显示开关，应用销毁后不会自行恢复。

历史每世界最多读取 50 条。新记录按追加顺序保留，系统时间回拨不改变新旧；旧记录不强制迁移。用户脚本按独立 localStorage 键追加，兼容只读旧根，避免多标签覆盖；并发期间底层记录可暂时超过 50，稳定追加后裁剪。保存失败会回滚面板并显示错误。扩展裁剪只依据完整的已提交快照，未决写入不挤掉旧记录，读取失败时跳过删除。实现见[面板与历史](../architecture/browser-runtime.md#状态面板与历史)。

“推理状态：完成 Nms”记录识别请求耗时，含图片传输、排队和必要重试。答题记录耗时从模型准备开始：自动模式截至提交点击，手动模式截至结果记录，包含其间图片读取、识别和配置等待；不含扫描前加载/防抖或提交后服务器响应。两者使用页面单调时钟，显示时刻仍为本地时间，旧记录不补算。

## 输入格式

| 输入          | 范围与示例                                                             |
| ------------- | ---------------------------------------------------------------------- |
| 点击/提交延迟 | 0–30000 毫秒整数或 `min-max`，如 `500`、`500-1000`；最小值不大于最大值 |
| 面板位置      | 非负整数 `top,left`，各不超过 1000000；重置恢复默认位置                |
| 历史显示条数  | 1–50 的整数，不改变每世界读取上限                                      |

## 存储和恢复

用户脚本普通设置由 GM 适配器保存，历史在同源 localStorage；Key 只允许敏感 GM 存储，不降级到页面存储。扩展普通设置和历史在 `storage.local`，远程 Key 在扩展源 IndexedDB。切换扩展为内置模型版不会读取或删除原 Key。

面板隐藏时仍可能执行识别和自动提交。希望只显示识别建议时请选择 `manual`；需要停止运行时停用对应客户端。不要在同一浏览器配置中同时启用用户脚本版和扩展版。
