# Agent Note: 额度时间边界、结果交付取消与审计工具复用

Status: implemented

## Problem

额度 DO 在异步存储读取前固定月份和 TTL 时间，等待跨边界后仍可能确认已过期回执或返回旧月状态。公开额度接口直接展开内部响应，允许额外字段透传甚至覆盖 `enabled`。扩展内容客户端收到成功消息后、异步续体执行前发生取消或销毁时，旧结果仍可能返回。

构建审计只检查小写 `.html`，遗漏其他 HTML 后缀；模型长度明显错误时仍先读入全部文件。用户脚本构建测试继承可选输出路径，可能写到 fixture 外。文档围栏、基准身份和 Release fixture 存在重复实现。

## Decision

- status 及 reserve/confirm 在各次状态读取完成后获取时间，事务重试重新判断月份和 TTL；公开响应显式选择契约字段。
- 内容客户端在编码前后及 Host 响应返回前检查取消与销毁。底层消息结算不免除调用返回前的生命周期复核。
- 所有 `.html/.htm` 文件统一按不区分大小写的后缀审计。内置模型读取前校验身份、普通文件及长度，读取后继续验证实际字节和摘要。
- 基准复用资产比较身份和现有摘要成功计数，移除未消费的逐次耗时数组及重复正确性扫描。Release 篡改测试复用同一个真实 ZIP fixture 构造器。
- 链接、命令示例和笔记格式检查共用 Markdown 围栏扫描器；笔记仍独立处理 HTML 注释。标题锚点按 base 记住下一个后缀，保留全局碰撞集合，避免重复标题的二次方搜索。
- 构建测试覆盖全部可选输出与 Runtime override，隔离调用者环境；菜单测试以 GM 存储验证失败/取消。链接测试统一注册临时目录清理。

检索现有决定后，本篇补充[有界 I/O 与生命周期](2026-09-29-bounded-io-and-lifecycle.md)、[MV3 边界](2026-09-29-extension-mv3-boundaries.md)、[文档重建](../process/2026-09-16-documentation-rebuild.md)和[测试归属](../testing/2026-10-14-test-suite-ownership.md)。原决定继续有效，没有同主题 proposed/rejected 笔记需要替换。

## Alternatives considered

- 请求开始时只获取一次时间：减少时钟读取，但不能正确处理异步等待和事务重试跨边界。
- 拒绝所有内部额外字段：能够失败关闭，但显式投影可保留内部扩展兼容性，同时保证公开字段集合。
- 仅依赖 Port 监听器取消：响应交付时已移除未决请求，仍需在异步返回边界复核。
- 引入完整 Markdown 依赖或改写各检查器：当前只需共用围栏状态；局部复用保留既有契约且不增加依赖。
- 直接删除失败测试或调整覆盖率门槛：会丢失行为证据；仅合并 fixture、参数化等价场景并移除已覆盖的重复用例。

## Consequences

公开 API、模型身份、月额度、回执有效期与客户端版本不变。修复使跨边界状态、取消后的结果及产物审计符合原有契约。围栏状态与标题后缀缓存仅活到当前文档扫描；后续调用重新读取文件。

依赖审阅没有发现可继续安全删除的直接依赖，保留锁定版本和供应链策略。行为回归、测试精简映射及实际验证见[本轮审计](../../../audits/2026-10-27-quota-and-tooling-audit.md)。
