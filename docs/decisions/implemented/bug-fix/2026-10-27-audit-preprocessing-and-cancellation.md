# Agent Note: 预处理归一化、内置资产取消与 Broker 准入精简

Status: implemented

## Problem

RGBA 转 CHW 在每个像素重复检查长度并执行三个通道归一化。Broker 对六种请求分别维护准入、计数增减和超时分支，增加新请求类型时容易遗漏。内置资产加载直接等待 Fetch，预取消仍发起请求，忽略取消的 Fetch 会继续占住加载等待。远程模型的非法 Content-Length 原文会进入错误提示。

依赖复核发现 undici 与 zod 的新增公告；根包还重复声明了仅由 Vitest 使用的 Vite，并残留已无工具入口的 Knip 配置。

## Decision

- RGBA 转换先验证像素数和输入/输出长度，复用 256 项 Float32 归一化表；保持 RGB 顺序、alpha 忽略及全部字节值的舍入结果。基准增加预热和多批次中位数。
- Broker 用穷尽请求类型的策略表读取上限、截止时间和提示，计数按类型独立。来源检查、独立清除池和取消后持槽规则保持原契约。
- 内置资产预取消不调用 Fetch；Fetch、流读取和摘要统一使用现有取消竞争助手。迟到正文尽力取消，删除包裹同步清理的异步转发函数。
- 非法声明长度使用固定错误，超限提示使用已经解析的安全整数。保留正文长度、SHA-256、额度及永久错误分类。
- undici 按原 major 分别更新到 7.30.1/8.12.2，zod 4 更新到 4.6.6；均已满足七天等待期。删除根 Vite 直接声明和两处无效 Knip 配置，保留 Vite override 与实际工具依赖。
- 将缩放、下载/额度准入、非法声明长度的重复测试改为数据表；保留原行为断言，补全全局容量释放、取消时点和原始头值脱敏。摘要取消回归按摘要阶段定位，不再依赖第几次移除监听器。

检索活跃决定后，本轮与 [10 月 23 日边界修复](2026-10-23-audit-boundaries-and-encoding.md)、[取消收尾](2026-10-22-audit-cancellation-and-ci.md)和[测试归属](../testing/2026-10-14-test-suite-ownership.md)部分重叠，沿用其安全与归属约束；未发现需要替代的 proposed/rejected 笔记。旧审计和旧性能数字保留原日期含义。

## Alternatives considered

- 只把逐像素检查移到循环外：实测未获得稳定收益，未作为最终优化方案。
- 用近似归一化或改变模型/输入尺寸提速：会改变数值或识别契约，本轮保持精确结果和现有资产。
- 合并 Broker 请求池：代码较少，但清除 Key 会被普通操作阻塞；采用共用实现、独立计数。
- 跨 major 统一 undici 或直接迁移 Cloudflare 测试插件：影响兼容边界，现有同 major 修复已覆盖公告。
- 按覆盖率或重复关键词删除测试：会丢失取消/事务/权限边界；仅精简等价测试结构。

## Consequences

每个推理 Worker 增加固定 1 KiB 归一化表，消除逐通道除法，预处理与原算法逐元素一致。Broker 少维护三组按请求类型复制的分支。内置资产取消及时结算，错误提示不再回显非法长度头。

依赖直接声明减少一项，传递图仍需要 Vite；本轮不新增依赖、不改变版本号或模型身份。验证方法、性能数据和实际运行结果见[本轮审计](../../../audits/2026-10-27-repository-audit.md)。
