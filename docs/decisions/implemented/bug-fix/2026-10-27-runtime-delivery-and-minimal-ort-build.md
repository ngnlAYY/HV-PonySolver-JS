# Agent Note: 异步结果交付与精简 ORT 构建依赖

Status: implemented

## Problem

图片/推理重试、额度查询、Key 验证、缓存下载和扩展模型管理的内部 Promise 已完成时，公开调用仍可能处于未决状态。此间取消或目标变化会让旧轮次更新状态、额外读取设置或返回成功。扩展设置镜像还会返回一个已经停止接收变更、但未移除监听器的实例。

ORT 精简构建在固定上游的三个 JS 目录运行独立 `npm ci`，引入实际 glue 构建不需要的测试、文档和 Electron 工具。根 pnpm 锁、override 与漏洞审计不覆盖这些安装。另有重复检测对象分配、产物文件重复读取、闲置平台 wrapper、纯常量/脚本文字测试，以及离线 Worker 测试配置的旧文档前提。

## Decision

- Solver 在图片与推理重试返回后复核当前目标，再写状态或读取设置。额度/Key API 复用已有 deadline 作公开交付检查；ModelCache 下载用关闭代次拒绝迟到成功，不增加计时器或缓冲复制。
- Host 公开方法同步分派，直接返回对应处理 Promise；模型操作在最终响应前复核意图。镜像快照等待后复核取消，沿已有失败路径销毁监听器。已交付的成功、已提交的 Key/缓存及服务端确认不回滚。
- YOLO 候选只构造、舍入一次，独立的检测数组复用只读前缀项；保留原始阈值判断、稳定同分顺序、top-N 上限与逐列校验。解压产物验证只在同次扫描复用两份 JSON 字节和模型摘要，下次调用重新读盘。
- 内置 E2E 逐项验证观察数组，稀疏项不能生成通过证据。危险调用检查剥离 `<T>` 与 `as` 类型断言。发布端原有 attestation 校验继续保留。
- 删除 ORT 上游三套 npm 安装、prepare 和修改 build.ts 的字符串补丁。新构建器仅打包固定 web/common 源码与实际 Emscripten 模块，使用根锁的 esbuild、Terser 和已有 TypeScript AST；保留两轮压缩、精简标志、许可声明与 source map。拒绝 ES module import、未知 require 和未解析构建标志，仅保留固定上游按浏览器环境分支隔离的三个 Node require fallback。
- 根包删除无消费者的原生 TypeScript CLI 声明，五个工作区继续直接声明 CLI。新增实际构建所需 esbuild/Terser，不改变七天等待或 trust policy，也不替换已采用的模型、glue、WASM。
- 删除经引用核对无消费者的设置 wrapper、cache helper 重导出和 core 历史条数清除接口。测试精简按[测试归属决定](../testing/2026-10-14-test-suite-ownership.md)执行，保留安全、并发和真实产物断言，coverage 配置不变。
- 文档按实际 Vitest 配置改为自动隔离测试绑定；普通测试/构建不覆盖根 Wrangler 配置。显式 dev/deploy 与临时配置渲染仍遵守原保护流程。

检索现有记录后，本篇补充[交付边界与审计归并](2026-10-27-delivery-boundaries-and-audit-ownership.md)、[预处理与依赖复核](2026-10-27-audit-preprocessing-and-cancellation.md)及测试归属决定，不推翻其生命周期、安全或资产身份约束；没有需要替代的同主题 proposed/rejected 记录。历史测试数与依赖结果保留原日期。

## Alternatives considered

- 只在底层完成时检查取消：仍留下公开续体窗口。反过来撤回已经交付成功或假称回滚 commit，也不符合实际副作用边界。
- 为每层新增通用取消框架：扩大状态和维护面；使用现有 deadline、关闭代次与阶段检查即可覆盖已证实问题。
- 更新整个上游 npm 图：继续安装无用途工具，部分公告无兼容修复或需跨 major/等待期例外。移除未使用的安装路径更符合实际最小构建职责。
- 为保持旧 glue 哈希继续使用旧编译器：把工具版本与资产身份混为一谈。生成字节可以变化，但采用新 vendor 前须完整更新清单并验收，不能悄悄沿用旧摘要。
- 仅因重复或覆盖率低删掉边界测试：不能证明场景等价。保留独立排序 oracle、实际文件/ZIP 哈希、Worker HTTP/DO、取消时序及原生浏览器验证。

## Consequences

公开结果交付前多一次常数级状态检查，失效轮次不会再启动无用设置读取。YOLO 每次最多减少 16 个检测对象及相应舍入；产物验证减少一次完整模型读取与哈希。两个列表的数组仍独立，检测项保持只读。

根 npm 图从 363 增至 369 个唯一包版本，用六个受锁管理的 Terser 闭包成员替代上游三套安装所涉及的 679 个包版本；这不是宣称根图减少 679 项。原图的 19 个包版本命中 49 条不同公告，已不再经本项目 JS 构建安装。此发现不证明已分发的 Runtime 可被利用。

构建器与上游固定实现存在需要维护的对应关系；以后更新 ORT 必须核对实际构建标志、WASM 变换及浏览器推理。新 esbuild 的初始化异常缓存改变生成字节，现有 vendor 身份保留。源码覆盖、实测性能、依赖公告、构建与浏览器证据见[本轮审计](../../../audits/2026-10-27-runtime-and-dependency-audit.md)。
