# Agent Note: DOM 快照复用、单调期限与跨后台恢复

Status: implemented

## Problem

第二轮从上一轮未提交工作树继续复核。SVG 命名空间的同名 img/form 会让扫描抛错；正常目标扫描重复读取原生 action，最终裁剪为选一个自动项反复分配数组和排序。

缓存显示耗时及跨阶段期限仍受墙钟跳变影响。凭证修订号依赖时间和进程内计数，后台重启后同一时钟值会重复，内容页因新旧值相等漏掉恢复。external Worker 启动队列只验证 requestId，畸形消息可抢占两个槽位。Worker 的额度期限从摘要之后才开始，摘要挂起和迟到均在预算外。

源码门禁可跳过符号链接或接受解析器错误恢复后的残缺树；字符串事实保留转义原文，会漏掉转义拼写的 query Key。模型清单还接受可变声明和零字节模型，两个资产 CLI 会忽略拼错的参数。CI 内置 Runtime 预算使用压缩包，与未压缩预算契约不符。

## Decision

- 扫描先验证实际 HTML 元素类型，常见单题走 ID 索引；首候选无效时回退后续同 ID 容器。同次同步校验只读一次原生 action，复用解析后的表单/提交地址；每次等待和点击仍重新验证。最终裁剪单遍计数并取最低自动置信度，同分保持 DOM 顺序。
- 缓存 API 保留绝对墙钟 deadline 入参，在操作上下文入口换算一次单调期限；打开、摘要、事务和确认共享剩余预算。显示耗时改用单调时钟，持久化时间戳不变。
- 每次凭证提交生成独立 UUID 修订令牌；消费者只做相等比较，旧字符串继续有效。external 启动队列复用核心 `isWorkerRequest`，畸形消息不入队，不复制 schema。
- 额度依赖总期限覆盖 Key 摘要、DO 定位、Fetch 和有界正文读取；摘要迟到时先查取消，不继续发起 DO 调用。
- 源树收集拒绝链接根和条目，保留生成目录排除；架构与危险调用门禁拒绝 AST 语法错误。字符串值采用已有 TypeScript AST/scanner 的实际转义解码，模型清单要求 const 和正安全整数字节数。资产 CLI 复用共享参数解析器。
- 删除两层 `solverConfig` 包装，默认随机兜底直接读取 `DEFAULT_RANDOM_ON_FAIL`；删除配置回声和平台重复 Fetch receiver 测试，保留默认答题行为与核心下载/确认 receiver 回归。CI 两种预算均使用未压缩产物，发布仍可压缩。

本篇补充[前轮决定](2026-10-29-intents-and-audit-tooling.md)、[生命周期与路径边界](2026-10-15-audit-lifecycle-and-path-boundaries.md)和[测试归属](../testing/2026-10-14-test-suite-ownership.md)。前轮保留原始字符串提取的取舍由本篇更正为实际转义值；其余取消、ZIP 与持久化边界保留。相关活跃记录没有需移除的 proposed/rejected 项。

## Alternatives considered

- 跨 await 或 abort 复用 DOM 快照：取消监听器也会同步改变页面，不能省掉这些边界后的复核。
- 维持全排序选最小项：只需一个候选且同分顺序明确，单遍选择更直接，无需通用堆或排名抽象。
- 用更大的时间戳或进程计数生成修订号：仍无法保证后台代际独立，随机令牌更符合仅比较相等性的用途。
- 改变缓存 deadline 的公开单位：会破坏既有调用者；入口转换既保留接口，又固定单次操作预算。
- 继续手写转义规则或添加新的解析依赖：已有 TypeScript API 足够，复用可避免不完整的语义实现。

## Consequences

没有新增依赖、模型字节或权限。目标读取减少重复工作，但异步、重入与手动归属复核保留；默认模式和额度规则不变。更严格的工具入口会拒绝原先被静默接受的无效源码、清单和参数。
