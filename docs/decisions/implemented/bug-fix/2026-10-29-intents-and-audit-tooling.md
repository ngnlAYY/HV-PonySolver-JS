# Agent Note: 排队意图、结果交付与审计工具收敛

Status: implemented

## Problem

用户脚本验证成功的 Key 在等待旧 GM 写入时，还可能被新意图淘汰；原代码只在入队前检查，旧 Key 仍会实际写入。扩展设置请求在 Port 响应结算后、公开结果交付前取消，仍可能返回成功；用户脚本 Runtime 资产在摘要结算后也存在相同交付窗口。GM 原始存储异常和部署探测的响应头错误还可能回显敏感输入。

文档事实提取同时维护手写 TypeScript 扫描器与编译器 AST；类型与函数体边界重复实现，维护成本高。活跃决策目录或笔记被换成符号链接时，检查器会跟随生命周期目录或静默遗漏分类/文件。仓库 CI 仍预生成已不再使用的根 Wrangler 测试配置。

## Decision

- Key 验证完成与排队写入实际开始前都复核意图代次。淘汰的排队项不写入、不通知提交；实际已发起 GM 写入继续按原串行契约结算。敏感 GM 失败转换为固定操作错误，普通设置保留原错误。
- 用户脚本 Runtime 资产在摘要结算后、交付字节前复核取消，保留调用方取消原因和原完整性校验。
- 扩展四类模型管理请求在最终交付前复核取消，包含额度断连后的一次重连；已提交的存储或服务端确认不撤销。
- 部署探测保留失败字段、预期值与请求分类，去除响应头原值及其异常链回显。
- HTTP 常量和函数体统一从 TypeScript AST 提取。缓存按完整源码键控，最多八份；只接受唯一顶层 const 字面量和唯一函数实现，跳过无体重载，语法错误失败关闭。保留原始字符串值的提取语义，类型断言和括号仅允许包装完整字面量。
- benchmark 与 packaged E2E 复用有界 ZIP 读取器，避免基准入口直接无界解压。中央/本地头核对名称、flags、压缩方式及尺寸，流式本地尺寸允许为零；拒绝 Unix 链接/特殊文件；Node 原生 inflate 约束实际输出长度，避免预分配解压把伪造声明长度当成实际长度。只支持本项目生成的普通单盘 ZIP，拒绝 ZIP64、加密与分卷。保持路径、重复项、文件数、总量与声明身份校验；inventory 和解压树根补齐符号链接拒绝。基准维度与 bootstrap 样本使用逐项遍历，拒绝稀疏数组。
- 活跃笔记遍历复用目录条目，拒绝符号链接、断链、非目录生命周期及非普通 Markdown。归档独立封印和链接检查职责保持不变。
- 删除三个无消费者的 CI 根 Wrangler 渲染步骤及 CLI `explicitRepoRoot` 返回字段；命令说明行每次检查只定位一次。测试复用已有面板 mock，用户脚本删除由核心完整覆盖的设置等待取消用例；Broker 常量回声改为实际超时、取消和迟到结果断言。

本篇补充[交付与最小构建决定](2026-10-27-runtime-delivery-and-minimal-ort-build.md)、[审计职责归并](2026-10-27-delivery-boundaries-and-audit-ownership.md)和[测试归属](../testing/2026-10-14-test-suite-ownership.md)，不替代其已验证边界；检索的相关活跃记录中没有需要移除的 proposed/rejected 项。

## Alternatives considered

- 仅在入队或 Port 事件回调检查：会遗漏排队期间的新意图和调用方续体前的取消。
- 直接保留全部底层错误以便诊断：响应头与 GM 异常不受本项目控制，可能含原始 Key；固定分类与安全上下文足以定位失败层。
- 继续扩展手写类型/函数扫描规则：与已有 TypeScript 依赖重复；统一 AST 同时缩小实现与重复扫描量，不新增解析依赖。
- 跟随或跳过活跃笔记链接：会让通过结果与实际可维护文件不一致，拒绝并保留原文件更明确。
- 为减少数量删除并发、安全或真实产物用例：无法证明语义等价。只删除明确由核心承担的重复场景和常量回声，保留与新增实际边界回归。

## Consequences

本次不升级依赖或模型资产。AST 提取模块由 400 行减至 148 行，复用现有 TypeScript API；源码内容变更会形成独立缓存项。新增取消检查均为常数级，历史副作用不会被描述为回滚。

可复现发现、性能测量、依赖核对与集成验证统一记录于[本轮审计](../../../audits/2026-10-29-repository-audit.md)。

后续[DOM 与恢复决定](2026-10-29-dom-snapshots-and-recovery.md)将本篇保留的原始字符串提取更正为实际转义值，修复转义 query Key 漏检；其余决定与本轮原验证记录保留。
